# Changelog

## [0.2.0] - 2026-10-09
### Added
- Rule-based classifier: category, subcategory and important flag
- Category labels and filter chips in the notification list
- System notifications (weather, alarms) hidden from "All"

### Changed
- Database structure changed; saved notifications are reset on update

## [0.1.0] - 2026-10-07
### Added
- Notification capture, local storage and live list
- Listener connection history
- Battery settings shortcut
## [0.2.1] - 2026-10-30
### Fixed
- Music and video playback notifications are no longer saved
- Financial detection: credit and debit now recognised from bank SMS and wallet alerts
- Promotional messages no longer appear under Financial
- Calendar events and action-required emails are flagged important
- System noise ("Checking for new messages", "Syncing new emails") is no longer saved
